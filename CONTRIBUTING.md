# Contributing Guide

We welcome contributions to Whitebox! There are several ways to get involved.

## Ways to Contribute

- **[Issue](https://github.com/TomokiMiyauci/whitebox/issues)** — Report bugs or other problems.
- **[Discussion](https://github.com/TomokiMiyauci/whitebox/discussions)** — Share ideas, ask questions, or discuss potential improvements.
- **[Pull Request](https://github.com/TomokiMiyauci/whitebox/pulls)** — Propose changes to the source code or documentation.
- **[Security Report](SECURITY.md)** — Report security vulnerabilities privately.

## Pull Requests

### Development Environment Setup

A [Dev Container](https://containers.dev) configuration is provided to help you set up the development environment.

### Creating a Pull Request

Fork this repository, make your changes in your fork, and submit a pull request to this repository.

Please refer to the [Pull Request Checklist](#pull-request-checklist).

Draft pull requests are welcome.

### Pull Request Checklist

To help ensure a smooth review and merge process, please consider the following:

- Using a pull request title that follows the [Conventional Commits](https://www.conventionalcommits.org) format.
- Running the following development checks locally.

```sh
bun check
bun test
```
